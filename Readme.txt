Aap ko kya karna hai
Adsterra par Publisher account banayein, apni site add karein, aur do ad units banayein: Banner 300×250 aur Banner 160×600. Phir har aik ka “Get code” kholein.
Zip mein ads-config.js kholein. Har slot ke code: mein backticks ke andar apna code paste karein. 300×250 wala code home, result aur books bottom teeno mein lag sakta hai, 160×600 wala books_side mein.
Sab se upar PSDC_ADS_ON = false ko true kar dein.
Sab files GitHub par upload karein, khaaskar ads-config.js, ads.js, app.js, index.html, books.html aur privacy.html.

Agar Adsterra verification ka code mange to wo mujhe bhej dein, main index.html mein laga dunga.

Do cheezein dhyan mein rakhein
Agar live site par ad blank aaye to ads-config.js mein PSDC_ADS_SANDBOX = false kar ke dekhein. Is ka matlab ye hai ke kuch ad scripts frame ki pabandi ke saath render nahi hotin.
Apne ads par khud click na karein, warna Adsterra account block kar sakta hai. Students se bhi ads par click karne ko na kahein.

Pehle sirf home aur result ka code laga ke aik hafta dekh lein ke ads theek dikh rahe hain, phir baqi slots mein code daalna chahein to daal dein.
